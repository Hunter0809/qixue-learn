启学智伴是一套面向学生日常学习场景的个性化学习系统。项目将多智能体编排、学习画像、错题分析、资源生成、复习规划和学习效果评估连接成完整闭环，让 AI 不只回答当前问题，还能根据学习行为持续更新对学生的理解，并据此调整后续资源与任务。

系统覆盖拍照搜题、智能答疑、作业与作文批改、口语练习、词典查询、拍照翻译、口算批改、文档扫描、背诵助手和课程推荐等工具，同时提供目标管理、错题归档、复习计划、学习报告和家长报告等长期学习能力。

## 设计理念

普通学习工具往往只完成一次问答或一次批改，学习数据停留在相互隔离的功能中。启学智伴以“感知—诊断—规划—执行—反馈—优化”为主线，把学习目标、答题表现、错题、资源使用和任务完成情况沉淀为动态画像，再由多个智能体协同生成下一步行动。

项目强调三个原则：结果必须能继续执行，过程必须可以追踪，模型输出必须经过结构校验。AI 生成的讲解、计划和报告会进入资源库、复习计划、错题记录和学习报告，形成持续迭代的学习过程。

## 核心功能

### 个性化学习工作台

首页集中展示学习状态、今日任务、薄弱知识点、推荐资源和近期进展。统一应用外壳提供各学习工具、资源、计划、报告和个人画像的入口。

### 多智能体学习闭环

服务端将画像分析、任务理解、资源生成、计划制定和效果评估拆分为明确职责。智能体以结构化数据交接结果，并通过 Schema 校验限制字段、类型和数值范围。

### 学习画像与行为追踪

系统记录学习目标、薄弱点、任务完成情况、资源状态和关键学习行为。画像会参与资源推荐、复习规划和学习报告生成，使推荐依据随学习过程持续变化。

### 错题、测验与复习计划

用户可以上传错题、分析错误原因、生成针对性练习并归档复习。测验结果更新掌握情况，复习计划根据目标、薄弱知识点和任务进展组织阶段任务。

### 多模态学习工具

系统提供拍照搜题、拍照翻译、文档扫描、口语练习和公式渲染等能力。OCR、本地词典、Markdown/LaTeX 渲染和 AI 服务共同支撑图片、文本、公式与结构化答案的展示。

### 资源与学习报告

生成的讲义、练习和课程资源可以进入资源库并维护处理状态。报告模块汇总学习行为、掌握度、任务完成情况和薄弱点，支持学生复盘和家长阶段性了解。

## 关键工作流

### 智能答疑工作流

用户提交问题后，系统识别学科与任务类型，结合学习画像组织上下文，由模型生成结构化讲解。回答可以包含 Markdown、公式、步骤和学习建议，本次行为会写入学习记录。

### 错题复习工作流

用户上传或输入错题，系统提取题目与答案信息，分析错误原因和相关知识点，随后生成针对性讲解或练习。错题可以被复习计划、薄弱点分析和学习报告继续使用。

### 个性化规划工作流

系统读取用户目标、当前画像、薄弱点和历史任务，生成阶段目标与可执行任务。任务完成情况与测验结果回流到画像，下一轮计划据此调整资源难度、任务密度和复习重点。

### 资源生成工作流

资源请求进入多智能体编排层，经过需求解析、内容生成和结构校验后写入资源任务与缓存。前端通过资源状态接口获取进度和结果。

## 关键技术

项目使用 Next.js App Router、React、TypeScript 和 CSS 构建 Web 应用，使用 Zustand 与 SWR 管理前端状态和数据请求，通过 Zod 校验智能体返回的结构化数据。AI 能力由 DeepSeek 接口提供，公式展示使用 KaTeX，图表使用 Recharts，图片识别使用 Tesseract.js，数据表格处理使用 SheetJS。

### 多智能体编排

`web/lib/multi-agent-orchestrator.ts` 负责组织学习任务，`web/lib/agent-deepseek.ts` 负责模型调用和流式响应，`web/lib/schemas.ts` 定义结构化输出约束。任务逻辑与页面组件分离，便于替换模型、扩展智能体职责和定位异常。

### 数据持久化

`web/lib/server-db.ts` 提供服务端数据访问，支持本地开发数据与 PostgreSQL/Neon 服务；`web/lib/learning-persistence.ts`、`profile-storage.ts` 和 `store.ts` 分别处理学习记录、画像与前端状态。

### 内容与本地资源

项目内置教材知识数据、教育视频索引、学校目录、英汉词典和白噪声音频，并提供相应的数据抓取、下载与校验脚本，为模型能力补充可追溯的本地检索和学习辅助。

## 项目结构

```text
Softwarecup/
  database/                  # 数据库初始化与项目数据
  web/
    app/                     # 页面与 API 路由
    components/              # 通用组件和学习工作区
    lib/                     # 智能体、画像、存储与业务逻辑
    public/                  # Logo、音频、词典和教育数据
    scripts/                 # 数据获取、校验与冒烟测试
    test/                    # Playwright 与接口测试
    package.json             # Web 应用依赖与脚本
  package.json               # 根目录统一命令入口
```

仓库根目录只保留项目代码、运行所需数据和项目文档。演示文稿生成脚本、PPT/PDF 输出、渲染图片、构建缓存、日志和本地密钥均排除在版本控制之外。

## 环境变量

在 `web/.env.local` 中配置本地环境变量：

```bash
DEEPSEEK_API_KEY=你的 DeepSeek API Key
DEEPSEEK_STREAM_TIMEOUT_MS=60000
DEEPSEEK_MAX_TOKENS=8192
DEEPSEEK_JSON_MODE=0
DATABASE_URL=可选的 PostgreSQL 或 Neon 连接地址
```

`DEEPSEEK_API_KEY` 用于智能答疑、资源生成、计划和报告等模型能力。不要提交 `.env`、`.env.local` 或任何包含真实密钥的文件。

## 快速开始

```bash
npm --prefix web install
npm run dev
```

浏览器打开 `http://localhost:3000`。

生产构建：

```bash
npm run build
npm run start
```

npm --prefix web run test:api

## 数据脚本

```bash
npm run download:dictionary
npm run download:schools
npm run discover:k12-schools
```

这些脚本用于更新词典和学校目录等项目数据。教育视频与教材知识脚本位于 `web/scripts`，运行前应确认数据来源、网络环境和目标文件。

## 当前适用场景

启学智伴适用于学生日常答疑、错题复习、阶段测验、学习目标管理、个性化资源生成和学习效果复盘，也可作为多智能体教育应用、结构化大模型输出、学习画像和教育数据持久化的工程参考。

项目当前以中文学习场景为主，后续可以继续扩展教师端、班级协同、更多课程知识库、模型可观测性和私有化部署能力。
